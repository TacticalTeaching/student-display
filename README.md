# Classroom Displays

Simple calculators and interactive displays for the classroom. Plain HTML, CSS and JavaScript. No build step and nothing to install.

## What's here

| File | What it is |
|---|---|
| `index.html` | Home page that links to every tool |
| `css/style.css` | Shared black, white and grey style (large text, touch friendly) |
| `tools/calculator.html` | Big on-screen calculator (works with the keyboard too) |
| `tools/timer.html` | Countdown timer with progress bar and beep |

## Adding a new tool

1. Copy an existing file in `tools/` and rename it (for example `tools/fractions.html`).
2. Change the title and the content inside `<main>`.
3. Add a card for it in `index.html`.

## Putting it online (GitHub Pages)

1. On GitHub, go to **Settings → Pages**.
2. Under **Source**, pick the `main` branch and the `/ (root)` folder.
3. Your site will be at `https://<your-username>.github.io/student-display/`.

Works on Chromebooks, laptops, tablets and the classroom screen.
