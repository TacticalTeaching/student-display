# Standalone versions

Each file here is one self-contained HTML file. The styles are built in and there are no links to other files.

Use these when you want to put a single tool somewhere else:
- Upload it to Google Drive, a website builder, or another app
- Paste the code into an HTML embed box (for example Google Sites: Insert → Embed → Embed code)
- Open it straight from a USB stick or a Chromebook's Downloads folder
